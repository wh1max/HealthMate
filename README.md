# HealthMate AI

HealthMate AI is a web application that helps users understand their potential health issues using AI. It asks the user to describe their symptoms, analyzes the input, asks clarifying follow-up questions, and then generates a short, personalized health summary that is sent to their email.

**Disclaimer:** This application is for informational purposes only and is not a medical diagnostic tool. Always consult with a qualified healthcare professional for any health concerns.

---

## Features

-   **Symptom Analysis**: Users can input their symptoms in natural language.
-   **AI-Powered Questions**: Generates dynamic, clarifying yes/no questions based on the user's input.
-   **Personalized Summary**: Creates a health summary based on the user's symptoms and their answers to the questions.
-   **Email Delivery**: Sends the final summary directly to the user's email address.
-   **Clean UI**: A simple, responsive, and easy-to-use interface.

---

## Tech Stack

-   **Backend**: Flask (Python)
-   **Frontend**: HTML, CSS, Vanilla JavaScript
-   **AI**: OpenAI-compatible API (configured for OpenRouter)
-   **Email**: Flask-Mail

## Setup and Installation

Follow these steps to get the application running locally.

### 1. Clone the Repository

First, clone the repository to your local machine (or simply use the files you already have).

```bash
git clone <repository_url>
cd HealthMate
```

### 2. Create and Activate a Virtual Environment

It is highly recommended to use a virtual environment to manage project dependencies.

```bash
# Create the virtual environment
python3 -m venv venv

# Activate the virtual environment
# On macOS/Linux:
source venv/bin/activate
# On Windows:
# venv\Scripts\activate
```

### 3. Install Dependencies

Install all the required Python packages using the `requirements.txt` file.

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

The application uses a `.env` file to manage sensitive information and configuration settings.

-   Rename the `.env.example` file to `.env` (or create a new `.env` file).
-   Update the values as described below.

#### AI Provider Configuration (OpenRouter)

This project is configured to use [OpenRouter.ai](https://openrouter.ai/) to handle AI requests.

-   **`OPENAI_API_KEY`**: Your API key from OpenRouter. You can get one at [openrouter.ai/keys](https://openrouter.ai/keys).
-   **`OPENAI_API_BASE`**: The base URL for the OpenRouter API. This should be `https://openrouter.ai/api/v1`.
-   **`AI_MODEL`**: The model you want to use (e.g., `openai/gpt-3.5-turbo`, `google/gemini-flash-1.5`).

#### Email Configuration (Mailtrap Recommended)

For development, it is highly recommended to use [Mailtrap.io](https://mailtrap.io/) to test email sending without spamming real inboxes.

-   **`MAIL_SERVER`**: `smtp.mailtrap.io`
-   **`MAIL_PORT`**: `587`
-   **`MAIL_USE_TLS`**: `True`
-   **`MAIL_USE_SSL`**: `False`
-   **`MAIL_USERNAME`**: Your Mailtrap username.
-   **`MAIL_PASSWORD`**: Your Mailtrap password.

---

## Running the Application

Once you have completed the setup and configuration, you can start the Flask development server.

```bash
python app.py
```

The application will be available at [http://localhost:5000](http://localhost:5000).

---

## How to Use

1.  **Open the App**: Navigate to `http://localhost:5000` in your web browser.
2.  **Enter Symptoms**: Describe your symptoms in the text area.
3.  **Analyze**: Click the "Analyze Symptoms" button.
4.  **Answer Questions**: Answer the yes/no questions generated by the AI.
5.  **Enter Email**: Provide your email address.
6.  **Get Summary**: Click "Get Summary" to see the result on the screen and receive it in your email inbox.
